# Club and player name editing

`change` / `CHANGE` now follows BASIC 9400–9599: four pages of sixteen clubs,
then three groups of eight players, including players outside the squad.
`99` wraps the pages; selecting a number from another page is refused. Only
`y`, `Y`, `yes` and `YES` accept a question. `h` / `H` copies during selection,
name entry and confirmation, but declines either initial question. Returning
to management preserves finances and the RNG seed.

Club names accept ten bytes without a prefix or twelve including `INK`
(byte 16) and colour 0–4. A plain name replaces the colour prefix and occupies
all twelve bytes of the fixed-width club string; its printed colour inherits
the current PRINT colour. Player names occupy eight bytes. Empty input retries.
The first name byte must be 65–122, so punctuation between `Z` and `a` remains
valid. Spectrum byte 96 is displayed as `£`. Validation order and messages are
preserved, including the original `3 Subscript wrong` stops at 9472/9473 for
truncated colour prefixes. A stopped edit retains the game in memory and hides
input; browser refresh starts a fresh game. General BASIC command recovery is
not implemented.

Edits update the live catalogue used by status, squad, transfers, fixtures,
results, league tables, highlights and subsequent season movements. Selling
retains the buyer's club number so identical edited names cannot confuse its
colour. Player attributes and ownership are unchanged.

## Original evidence

`tools/zx/capture-names.ts` runs the fresh-program menu checkpoint generated by
the earlier capture workflow. It checks BASIC hash
`5289e111f8f041fa9a58ae41e0567e31951d41552702bd2f525acae71bf6ece6`, types
through the original menus, then replaces placeholder bytes in the ROM line
editor's buffer before Enter. It does not patch the game's validation code.
The optional runtime is SkoolKit 10.2 through `uv`.

```sh
bun tools/zx/capture-names.ts roms/zx/analysis/24-fresh-menu.z80
```

`web/src/sim/fixtures/names.json` records 31 inputs with fixed-width storage,
seed, BASIC line and screen text, plus two renamed first-fixture observations.
Tests compare accepted storage and original errors, the first 22 screen rows
after one edit attempt, fault reports, fixture padding and inherited/explicit
ink. Session tests cover paging, repeat edits, copying, unowned players and
unchanged RNG state. The committed fixture contains observations, not the
original program or snapshot.

## Remaining presentation limits

The browser still uses its native line editor. Spectrum keyboard mode/colour
chords and the ROM cursor are not reproduced; a raw prefix can be supplied as
control bytes, but there is no added colour-picker flow. Unsupported Unicode
is refused. Extended graphics and embedded control bytes inside names retain
their data but do not have a complete Spectrum PRINT interpreter. Cumulative
scrolling after repeated invalid inputs, wrapping of twelve-column plain club
names in the strength display and large edited season summaries remain to be
verified. The captured single-attempt name screens include their original
scroll offset. Existing font, prompt sound and pacing limits remain.

Saving is still unavailable.
