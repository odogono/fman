# Preserve the original experience before enhancing it

The initial web recreation of ZX Spectrum Football Manager will preserve the original rules, balance, quirks and observable bugs, together with its screen layouts, wording, keyboard controls, match presentation and pacing. Fidelity takes priority over fixes and modernisation so that the recreation establishes a reference experience before intentional enhancements are introduced in a later phase.

The supplied snapshot is the provisional reference edition. Its identity and completeness must be established before it is treated as authoritative. The initial target is desktop browsers with keyboard input; touch controls and responsive layouts belong to the later enhancement phase.

The [initial analysis](../original-game-analysis.md) subsequently established that the snapshot's BASIC is byte-for-byte identical to the compared archived original-release tape. Use the snapshot for continued-play evidence and that tape's saved variables for fresh-game initialization; the snapshot contains a progressed, renamed club.

The user's local `Football Manager.tzx` was then verified byte-for-byte identical to the archived tape. Prefer that supplied tape for fresh-game initialization; the archive comparison supplies corroborating provenance.
