# Rulesets carry their starting clubs and players

Present-day clubs and players arrive as part of the Enhanced rules (`enhanced-3`), not as a separate choice: a ruleset is now its game rules together with the starting clubs and players a new game begins with, and the Original rules keep the 1982 set. The same version gives every club a name colour and a home and change kit from its real colours, so the Original rules' black-or-white colour question is dropped from new Enhanced games. Players already choose a ruleset when starting a game; adding a second, independent choice for the names would double what a newcomer must decide, for a combination (1982 names under Enhanced rules) few would want.

## Considered Options

- A separate choice of clubs and players, independent of the ruleset. Cleaner in definition, but a second new-game choice.
- Present-day names for everyone. Breaks rules parity's promise that the Original rules reproduce the Spectrum game.

## Consequences

Kits are not cosmetic: highlights tell players from grass and home from away by screen attribute, so a kit must never be yellow (the grass's ink), and the two sides must never share one. Within those limits the matches play out exactly as with black and white, which is why `enhanced-3`'s gameplay baseline is expected to match `enhanced-2`'s. The present-day set is fixed to one season and changes only in a later Enhanced version.
