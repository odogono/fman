**New games play Enhanced rules: the original game with a smoother difficulty curve.** Each difficulty level is now a real step up, and even Genius can be won: a well-run club still wins promotion. To play exactly as the 1982 Spectrum game did, choose Original rules under New game in the game menu; the game remembers your choice. The menu and save slots show which rules a game uses, and a game keeps its rules for good, so games you have already started stay Original (#84).
