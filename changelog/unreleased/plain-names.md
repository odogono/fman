**A renamed club or player can no longer end an Enhanced game.** The original lets you type Spectrum colour and cursor codes into a name, and a bad one stops the game the next time the name is printed. New Enhanced games now refuse those codes as an invalid name and ask again. A club's leading colour, graphics blocks and BASIC keywords still work. Games you've already started, and the Original rules, keep the original's behaviour.
